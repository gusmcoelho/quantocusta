# QuantoCusta

Comparador internacional de preços de jogos da Steam e assinaturas de IA (ChatGPT Plus, Claude Pro, Gemini Advanced) em 18 países, com conversão direta para Real (BRL).

Acesse o site: https://gusmcoelho.github.io/quantocusta/

## Funcionalidades

- Jogos da Steam: Busca em tempo real na API oficial com preços de 18 países.
- Assinaturas de IA: Comparativo de mensalidades do ChatGPT Plus, Claude Pro e Gemini Advanced.
- Conversão de Moedas: Valores convertidos para Reais (BRL) e Dólares (USD) com cálculo de diferença percentual.
- Interface responsiva com tema escuro.

## Tecnologias

- Frontend: React, TypeScript, Vite
- Proxy: Cloudflare Workers
- Hospedagem: GitHub Pages

## Como rodar localmente

```bash
cd frontend
npm install
npm run dev
```
